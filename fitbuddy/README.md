# FitBuddy – AI Fitness Plan Generator

FitBuddy is a FastAPI web application that uses Google Gemini to generate personalized 7-day fitness plans and nutrition/recovery guidance.

The project includes:

- FastAPI backend
- Jinja2 frontend
- SQLite database
- SQLAlchemy ORM
- Google Gemini integration
- Structured AI responses
- Feedback-based workout regeneration
- Admin dashboard
- REST API
- Automated tests
- Demo mode
- Docker support
- VS Code configuration

---

# 1. Requirements

Install:

- Python 3.11+
- VS Code
- Git (optional)
- Gemini API key for real AI generation
